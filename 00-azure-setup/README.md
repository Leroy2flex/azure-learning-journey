### What I Learned - SC-900 Concepts
- **Azure Portal:** The dashboard for all cloud resources
- **Subscription:** My $200 trial - this is the billing boundary
- **Resource Group:** Every resource must live inside a group - like a folder
- **Cost Management:** I must check costs daily so I don't run out of credits
- **Entra ID:** Identity is the new perimeter - this is where security starts
