# SecureCensus | My Journey to Cloud Security Engineer

**By Leroy Ngoma | Johannesburg, South Africa**
**Goal:** SC-900 → SC-300 → SC-400 → AZ-500 → SC-100 → SC-500
**Status:** Phase 1 - In Progress

### The Story
I worked as a Fieldworker at Stats SA. We were given tablets to capture census data - names, ID numbers, addresses, income. That is the most sensitive data in South Africa.

If a tablet was lost, stolen, or used by the wrong person, that data was at risk.

This portfolio is me rebuilding that entire system securely in Microsoft Azure - from identity to compliance to incident response.

### The Project: SecureCensus
A secure field data collection system for government census work.

**The Problem I Lived:**
- Tablets could be lost/stolen in the field
- Passwords were shared
- Fieldworkers could see data outside their area
- No way to prove who changed a record
- Sensitive PII could be emailed out

**What I'm Building in Azure:**
- Phase 1 [SC-900]: Entra ID, MFA, Groups, Secure Storage
- Phase 2 [SC-300]: Conditional Access, RBAC, PIM
- Phase 3 [SC-400]: Purview, DLP, Key Vault, POPIA Compliance
- Phase 4 [AZ-500 / SC-100]: Intune, Defender for Cloud, Private Endpoints
- Phase 5 [SC-500]: Sentinel SIEM, Incident Response
